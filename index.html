Conoce un poco más sobre Code Power

¿Qué es Code Power?

Code Power es un proyecto escolar desarrollado para practicar programación mediante diferentes juegos interactivos.

🎯 Objetivo

Crear una página web sencilla donde los usuarios puedan divertirse mientras se ponen en práctica conceptos de HTML, CSS y JavaScript.

💻 Tecnologías utilizadas

  • HTML para la estructura.
  • CSS para el diseño.
  • JavaScript para la programación.

🎮 Juegos incluidos

  • Ahorcado.
  • Adivina el número.
  • Tic Tac Toe.
  • Memoria.
  • Buscaminas.
