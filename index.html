SOBRE NUESTRO PROYECTO

¿Por qué creamos Code Power?

Creamos Code Power con el objetivo de aplicar nuestros conocimientos de programación de una forma práctica y divertida.

Elegimos desarrollar juegos porque queremos demostrar que la programación también puede ser entretenida y fácil de aprender.

En nuestro proyecto utilizamos HTML, CSS y JavaScript para crear la página y desarrollar nuestros juegos.
